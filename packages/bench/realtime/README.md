## What is implemented

MidStream protects interruption and cancellation with dedicated control latches before bounded data admission. Data queue saturation cannot discard a stop request. Adjacent interrupts replace only a still-pending event, control watermarks survive draining, and cancelled work is counted once per host-declared generation. A bounded versioned wire format uses decimal strings for u64 fields.

Ruflo consumes the wire contract through an opt-in RealtimeSession. It synchronously fences obsolete output, propagates AbortSignal through tracked reasoning, delegation and tools, and cancels actual fetch/ReadableStream consumption. Tool proposals are frozen and generation validity is rechecked after asynchronous authorization. A host that ignores abort is INCOMPLETE, remains busy, and cannot accumulate replacement work. RVM remains the actual privileged effect boundary.

No receipts, callbacks, or hashes establish transport authenticity. The host must authenticate the control channel, bind it to the session, and enforce resource bounds before parsing. The adapter is not a sandbox, cannot preempt synchronous CPU blocking on its own event loop, and cannot undo committed external effects.

## Executable checks

The workflow `.github/workflows/realtime-reproduction.yml` checks out pinned source repositories without retained credentials, compiles the exact modules, and runs:

1. 14 Rust controller tests, including full queues, draining, repeated controls, sequence overflow and malformed session identities.
2. 30 Node contract tests, including a real loopback HTTP provider, socket closure, pending reader cancellation, delegated work, tool approval races, resource exhaustion, stale output, and 1000 interrupted sessions.
3. 1000 additional cross-language sessions. The Rust fixture generator saturates every queue, produces real serialized handoffs, and the JavaScript evaluator requires acknowledgement, abort, stale-output rejection, local quiescence and replay rejection. More than 300 sequences exceed the JavaScript safe integer limit; one reaches u64::MAX.
4. A paired latency benchmark with a mandatory simpler AbortController control.

The cross-language fixture is generated by the real candidate, not hand-authored JSON representing intended behavior. Full repository integration, supply-chain and security gates remain separate mandatory release checks; standalone tests cannot substitute for them.

## Negative results and corrections

The original controller dropped cancellation when its data queue was full and could coalesce a new interruption against an already-drained one. New control-latch and draining regressions cover both.

The original Rust matrix did not test the root crate containing the reflex module. A new direct root-library validation job now checks it. Hosted Rust1.88 compilation and all 14 standalone and root tests pass. The newly added strict root lint exposed unrelated existing formatting warnings in two workspace dependencies; those source formatting errors are fixed without weakening the lint rule.

An initial timing run used fixed arm ordering. It is superseded by V2's randomized ordering. Direct AbortController already gives the structural latency improvement more cheaply; no superiority over that simpler mechanism is claimed. The bridge earns its overhead through bounded lifecycle management, typed session scope, stale-output fencing and effect checks.

The repository dependency audit has independent preexisting findings. No advisory is waived, ignored, or treated as green because this module adds no dependencies.

After compiling the pinned Ruflo module with `tsc -p v3/@claude-flow/integration/tsconfig.realtime.json`:

```sh
node --test /path/to/ruflo/v3/@claude-flow/integration/validation/realtime.contract.mjs
node packages/bench/realtime/benchmark.mjs \
  /path/to/ruflo/v3/@claude-flow/integration/dist/realtime-session.js \
  /path/to/ruflo/v3/@claude-flow/integration/src/realtime-session.ts \
  /tmp/realtime-results.json
```

Copy pinned MidStream `src/reflex.rs` to a temporary directory as `reflex-under-test.rs`, copy `wire-fixture.rs` beside it, compile with Rust1.88 using edition2021, and redirect its output to fixtures.jsonl. Run `wire-integration.mjs` with the compiled Ruflo module and that JSONL file. The CI workflow contains exact commands and pins.
